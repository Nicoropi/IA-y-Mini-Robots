# Despacho de energía eléctrica con Algoritmos Genéticos

## Problema

Cuatro plantas abastecen la demanda diaria de Cali, Bogotá, Medellín y Barranquilla.

| Planta | Capacidad (GW/día) | Costo generación ($/KW-H) |
|---|---|---|
| Planta C | 3 | 680 |
| Planta B | 6 | 720 |
| Planta M | 5 | 660 |
| Planta Q (Barranquilla)* | 4 | 750 |

| Ciudad | Demanda (GW/día) |
|---|---|
| Cali | 4 |
| Bogotá | 3 |
| Medellín | 5 |
| Barranquilla | 3 |

Costo de transporte por GW:

| | Cali | Bogotá | Medellín | Barranq. |
|---|---|---|---|---|
| Planta C | 1 | 4 | 3 | 6 |
| Planta B | 4 | 1 | 4 | 5 |
| Planta M | 3 | 4 | 1 | 4 |
| Planta Q | 6 | 5 | 4 | 1 |

\*El enunciado nombra "Planta B" a dos plantas; la cuarta se renombró **Q** para distinguirla.

**Modelo matemático** (problema de transporte):

```
min  Σi Σj ( c_ij + g_i ) · x_ij
s.a. Σj x_ij ≤ capacidad_i      (cada planta)
     Σi x_ij  = demanda_j       (cada ciudad)
     x_ij ≥ 0 entero
```

donde `x_ij` es el GW enviado de la planta *i* a la ciudad *j*, `c_ij` el costo de transporte y `g_i` el costo de generación.

## Algoritmo utilizado

**Algoritmo Genético generacional con codificación entera, restricciones por penalidad y un operador de mutación propio del problema.**

| Componente | Decisión |
|---|---|
| Cromosoma | 16 genes enteros (0 a 6) = matriz 4×4 de flujos `x_ij` aplanada |
| Función de aptitud | `1 / (1 + costo_total)`, con `costo_total = transporte + generación + penalidad` |
| Manejo de restricciones | **Penalidad alta**: 2000 por cada GW que excede la capacidad de una planta o que no coincide con la demanda de una ciudad |
| Selección | **Torneo** (tamaño 3) |
| Cruce | **Dos puntos**, probabilidad 0.9 |
| Mutación estándar | Por gen (p = 0.03): reinicio aleatorio o paso ±1 |
| Mutación dirigida | Mueve 1 GW entre plantas para una ciudad, o intercambia flujos en un "rectángulo" 2×2 (conserva producción y demanda) |
| Elitismo | Se conservan los 2 mejores individuos |
| Parada | 500 generaciones |
| Parámetros | Población K = 200, M = 500 |

Con solo operadores genéricos el AG quedaba ~0,25 % sobre el óptimo; la mutación dirigida lo lleva al óptimo en la gran mayoría de ejecuciones.

## Resultado

Despacho encontrado (GW/día):

| | Cali | Bogotá | Medellín | Barranquilla | Genera | Cap. |
|---|---|---|---|---|---|---|
| Planta C | 3 | 0 | 0 | 0 | 3 | 3 |
| Planta B | 1 | 3 | 0 | 2 | 6 | 6 |
| Planta M | 0 | 0 | 5 | 0 | 5 | 5 |
| Planta Q | 0 | 0 | 0 | 1 | 1 | 4 |

- Costo de transporte: **26**
- Costo de generación: **10 410**
- **Costo total: 10 436**
- Óptimo exacto (programación lineal con `scipy`): **10 436** → brecha **0 %**

La capacidad total (18 GW) supera la demanda (15 GW), así que el AG deja sin usar 3 GW en la planta más cara (Q, 750) y cada planta abastece a su propia ciudad cuando es posible.

Robustez: en 10 semillas (0 a 9), 9 llegaron al óptimo exacto (10 436) y una quedó en 10 448.

![Convergencia](images/convergencia_despacho.png)

## Supuestos

- Los flujos son **enteros** (con capacidades y demandas enteras, el óptimo del problema de transporte también lo es).
- El costo de generación por GW es el valor de la tabla, en la misma escala que el costo de transporte. Para convertir unidades, cambie `ESCALA_GEN` en el código.
- Hay oferta suficiente (18 ≥ 15), por lo que el problema es factible.

```python
"""
Ejercicio 3 - Despacho de energía con Algoritmos Genéticos
Minimiza costo de generación + costo de transporte.

Supuestos (el enunciado no los fija):
 * Las plantas son C(ali), B(ogotá), M(edellín) y Q (Barranquilla; el enunciado
   repite "B", aquí se renombra a Q para distinguirla).
 * Los flujos x[i][j] (GW de la planta i a la ciudad j) son enteros.
 * Costo de generación por GW = valor de la tabla $KW-H (misma escala que el transporte).
   Si se quiere otra escala, cambie ESCALA_GEN.
"""
import numpy as np
import random
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

# ----------------------------- DATOS ---------------------------------
plantas  = ["Planta C", "Planta B", "Planta M", "Planta Q"]
ciudades = ["Cali", "Bogotá", "Medellín", "Barranquilla"]
capacidad = np.array([3, 6, 5, 4])          # GW/día por planta
demanda   = np.array([4, 3, 5, 3])          # GW/día por ciudad
costo_transp = np.array([[1, 4, 3, 6],
                         [4, 1, 4, 5],
                         [3, 4, 1, 4],
                         [6, 5, 4, 1]])
costo_gen = np.array([680, 720, 660, 750])  # $/KW-H por planta
ESCALA_GEN = 1.0
N = 4

# ------------------------ PARÁMETROS DEL AG --------------------------
K = 200          # población
M = 500          # generaciones
P_CRUCE = 0.9
P_MUT = 0.03     # por gen
ELITE = 2
LAMBDA = 2000    # penalidad por GW que viola una restricción
GEN_MAX = int(max(capacidad.max(), demanda.max()))   # valor máx. de un gen

# ------------------------ CROMOSOMA / APTITUD ------------------------
# Cromosoma = lista de 16 enteros (matriz 4x4 aplanada): x[i][j] = GW de i -> j
def genera():
    return [[random.randint(0, GEN_MAX) for _ in range(N * N)] for _ in range(K)]

def decodifica(crom):
    return np.array(crom).reshape(N, N)

def costo_y_penalidad(crom):
    x = decodifica(crom)
    produccion = x.sum(axis=1)
    recibido   = x.sum(axis=0)
    costo = (costo_transp * x).sum() + ESCALA_GEN * (costo_gen * produccion).sum()
    viol = np.maximum(0, produccion - capacidad).sum() + np.abs(recibido - demanda).sum()
    return costo, LAMBDA * viol, viol

def costo_total(crom):
    c, p, _ = costo_y_penalidad(crom)
    return c + p

def aptitud(crom):
    # Minimizar costo  ->  maximizar aptitud
    return 1.0 / (1.0 + costo_total(crom))

# ---------------------------- OPERADORES -----------------------------
def seleccion(pob, apt, tam_torneo=3):
    """Selección por torneo (mantiene presión de selección estable)."""
    nueva = []
    for _ in range(len(pob)):
        cand = random.sample(range(len(pob)), tam_torneo)
        mejor = max(cand, key=lambda i: apt[i])
        nueva.append(pob[mejor][:])
    return nueva

def cruce(padres):
    hijos = []
    for i in range(0, len(padres), 2):
        a, b = padres[i], padres[i + 1]
        if random.random() < P_CRUCE:
            p1, p2 = sorted(random.sample(range(1, N * N), 2))   # cruce de 2 puntos
            h1 = a[:p1] + b[p1:p2] + a[p2:]
            h2 = b[:p1] + a[p1:p2] + b[p2:]
        else:
            h1, h2 = a[:], b[:]
        hijos += [h1, h2]
    return hijos

def mutacion(pob):
    for crom in pob:
        for g in range(N * N):
            if random.random() < P_MUT:
                if random.random() < 0.5:
                    crom[g] = random.randint(0, GEN_MAX)              # reinicio del gen
                else:
                    crom[g] = min(GEN_MAX, max(0, crom[g] + random.choice([-1, 1])))  # paso ±1
    return pob

def mutacion_dirigida(pob, prob=0.3):
    """Operador propio del problema: reasigna 1 GW sin alterar lo recibido por
    cada ciudad (mueve un GW de la planta a1 a la planta a2 para la ciudad j),
    o intercambia flujos en un 'rectángulo' (conserva producción y demanda)."""
    for crom in pob:
        if random.random() < prob:
            x = np.array(crom).reshape(N, N)
            if random.random() < 0.5:
                j = random.randrange(N)
                a1, a2 = random.sample(range(N), 2)
                if x[a1, j] > 0 and x[a2, j] < GEN_MAX:
                    x[a1, j] -= 1; x[a2, j] += 1
            else:
                i1, i2 = random.sample(range(N), 2)
                j1, j2 = random.sample(range(N), 2)
                if x[i1, j1] > 0 and x[i2, j2] > 0 and x[i1, j2] < GEN_MAX and x[i2, j1] < GEN_MAX:
                    x[i1, j1] -= 1; x[i2, j2] -= 1; x[i1, j2] += 1; x[i2, j1] += 1
            crom[:] = x.flatten().tolist()
    return pob

# --------------------------- ALGORITMO GENÉTICO ----------------------
def algoritmo_genetico(semilla=None):
    if semilla is not None:
        random.seed(semilla); np.random.seed(semilla)
    pob = genera()
    historia, mejor_global = [], None
    for gen in range(M):
        costos = [costo_total(c) for c in pob]
        apt = [1.0 / (1.0 + c) for c in costos]
        idx = int(np.argmin(costos))
        if mejor_global is None or costos[idx] < costo_total(mejor_global):
            mejor_global = pob[idx][:]
        historia.append(costo_total(mejor_global))
        # elitismo
        orden = np.argsort(costos)
        elite = [pob[i][:] for i in orden[:ELITE]]
        padres = seleccion(pob, apt)
        hijos = cruce(padres)
        pob = mutacion_dirigida(mutacion(hijos))
        pob[:ELITE] = elite
    return mejor_global, historia

# ------------------------------ EJECUCIÓN ----------------------------
if __name__ == "__main__":
    mejor, historia = algoritmo_genetico(semilla=7)
    x = decodifica(mejor)
    c, p, viol = costo_y_penalidad(mejor)

    print("=== Mejor despacho encontrado por el AG (GW/día) ===")
    print(f"{'':10s}" + "".join(f"{c_:>14s}" for c_ in ciudades) + f"{'Genera':>10s}{'Cap.':>6s}")
    for i in range(N):
        print(f"{plantas[i]:10s}" + "".join(f"{v:>14d}" for v in x[i]) +
              f"{x[i].sum():>10d}{capacidad[i]:>6d}")
    print(f"{'Recibido':10s}" + "".join(f"{v:>14d}" for v in x.sum(axis=0)))
    print(f"{'Demanda':10s}" + "".join(f"{v:>14d}" for v in demanda))
    print(f"\nCosto de transporte : {(costo_transp * x).sum():.0f}")
    print(f"Costo de generación : {(costo_gen * x.sum(axis=1)).sum() * ESCALA_GEN:.0f}")
    print(f"Costo total         : {c:.0f}   (violaciones: {viol})")

    # Verificación con programación lineal (óptimo exacto)
    try:
        from scipy.optimize import linprog
        cc = np.array([costo_transp[i, j] + ESCALA_GEN * costo_gen[i]
                       for i in range(N) for j in range(N)])
        A_ub = np.zeros((N, N * N)); b_ub = capacidad
        for i in range(N): A_ub[i, i * N:(i + 1) * N] = 1
        A_eq = np.zeros((N, N * N)); b_eq = demanda
        for j in range(N): A_eq[j, j::N] = 1
        res = linprog(cc, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, bounds=(0, None))
        print(f"Óptimo exacto (LP)  : {res.fun:.0f}")
        print(f"Brecha AG vs óptimo : {(c - res.fun) / res.fun * 100:.4f} %")
    except ImportError:
        pass

    plt.figure(figsize=(8, 4))
    plt.plot(historia)
    plt.xlabel("Generación"); plt.ylabel("Mejor costo total")
    plt.title("Convergencia del AG - despacho de energía")
    plt.grid(alpha=.3); plt.tight_layout()
    import os; os.makedirs("images", exist_ok=True)
    plt.savefig("images/convergencia_despacho.png", dpi=130)
```
